# quant-radar · A股量化交易驾驶舱（v9）

**一个页面**承载从"看行业 → 选个股 → 制定计划 → 对照执行 → 记录交易 → 前瞻验证"的完整闭环。
纯静态站点（GitHub Pages），公开行情接口，无服务器、无数据库，**每交易日 16:30 全自动更新**。

> 模型口径 v9：八因子打分 + 行业位置共振 + **质量因子（ROE/营收增速）** + 市场温度仓位调制 + 卖出参考；
> 消息面经 14116 条事件回测证伪（追"利好"是反向信号），仅作**排雷与背书**、不入打分。
> 完整数学公式与全部回测边界见 **`radar/MODEL.html`**（可视化文档，另有 `MODEL.md` 原稿）。

## 模型要点（v9）

```
综合分 Score = 位置20 + 估值12 + 启动18 + 板块(冷区14/其余0) + 换手9 + 资金13 + 波动8 + 流动20
             + 行业共振 Adj_ind（低位行业+金叉首启 +5 / 行业高位 −4）
             + 质量修正 qAdj（ROE>15 或 ROE>10且营收增 +3 / 微利或营收萎缩 −2）
市场温度 heat ∈[0,100] 只调建议仓位(20~65%)与信号档位，不切换打分
```

- **启动** = 距最近一次"低位金叉"(MA5×MA20 / MACD，金叉点须处一年低位) 天数：≤3日 98 分、≤7日 86 分。
- **质量**：财务按法定披露截止自动切换最新报告期（4/30 后一季报、8/31 后中报、10/31 后三季报），东财取数失败自动退回 v7 口径。
- **卖出参考**：估值状态(PE/同行中位) + 卖出区间（估值兑现带 / 短线止盈带，受一年前高钳制）+ 止损（金叉启动平台或 MA20 的 97%）。
- **已证伪并排除**：追"业绩利好"加分（14116 事件回测：预增次日买入 +2.99%/胜率57.3%，为最差组之一；利空出尽反而 +6.02%/68.4%）→ 消息只做排雷与背书。

## 自动更新与前瞻档案（GitHub Actions）

每交易日 **16:30（北京，UTC 08:30）** 一次运行：
1. `industry` 行业数据更新 → 2. `radar` 全市场扫描（v9 打分+质量）
3. **前瞻绩效评估**：每次扫描的榜单快照随 data.json 提交进 git 历史 = 每日档案；`prospect_track.py` 检查满 20/60 交易日的旧档案，自动拉现实行情评估当时 Top15 收益/胜率/超额 → 写入 `radar/prospect.json`（页面「前瞻」徽章与弹窗展示，**无前视偏差的真实样本验证**）
4. 数据有变化提交回 main → 整站发布到 gh-pages

手动触发：仓库 Actions → daily-scan → Run workflow。手动跑本地脚本见下方"本地运行"。

## 部署（GitHub 网页操作，无 git 命令）

1. 解压源码包 → 仓库 **Add file → Upload files** 整批拖入（含 `.github/`）→ Commit changes
2. **Actions → daily-scan → Run workflow** 跑一次（约 8~10 分钟）——负责发布站点并开始累积前瞻档案
3. 确认 Settings → Pages：Source=Deploy from a branch → `gh-pages`
4. 访问 `https://<user>.github.io/quant-radar/`（有缓存则 Ctrl+F5）

> 仅上传 main 不会更新网页——线上内容由 workflow 发布到 gh-pages，每次改完源码都必须 Run 一次。

## 本地运行 / 预览

```bash
cd industry && python scripts/update.py      # 行业数据（可选）
cd radar    && python scripts/scan.py        # 多因子扫描 v9（约 7~9 分钟，含质量财务拉取）
python -m http.server 8000                   # 预览 http://localhost:8000/
```

页面数据与行业映射等均以相对路径加载，http 下功能完整；浏览器直连东财业绩接口需要网络可达（不可达时消息层/质量自动降级，不影响打分执行）。

## 使用节奏（每日/每周）

- **盘后 16:30 后**：打开页面看当日新信号（数据时间显示在顶栏）
- **盘中**：实时盯盘等触发；持仓破位/进卖区会在纪律待办自动生成"今日执行"
- **执行后**：账本记一笔（加/减/清自动滚算现金与加权成本），待办点 ✓
- **每周**：账本 ⬇ 导出备份；检查逾期待办；回看「前瞻」评估批次数
- 持仓行业重复下注时页面会红字点名——同赛道至多留 1 只
