# A股多因子雷达（GitHub Pages 版）

每日对全市场 A 股做**低位 + 刚金叉首启**扫描的量化研究工具：全市场快照 → 市值候选池 → **市场温度**（连续因子）+ **八因子**打分 → Top 榜单。**数据每交易日自动更新，打开页面即可看到当天最新信号。**

页面定位为**每日交易闭环**：打开即看「市场温度 + 建议仓位 + 今日行动清单」；每只上榜股以**执行卡**呈现——买点（金叉首启/回踩启动平台/贴止损警告）→ 卖出区间（估值回归带或短线带，前高钳制）→ 止损纪律，并给出介入参考价、回撤空间与盈亏比，可直接对照执行。八因子（位/估/启/板/换/资/波/流）、板块因子状态、金叉徽章、估值口径说明与完整公式入口均保留。

> **选股哲学（低位、刚启动、不追高、不接飞刀）**：不给已暴涨/贴近一年高位的股票高分（位置因子直接惩罚），也不接深跌未止的飞刀；偏好**低位刚金叉（1~3日）的首启**标的（启动因子），并把行业、换手、主力资金纳入考量（板块因子仅冰点区激活）；市场温度连续调制只调仓位与档位。适合左侧分批、冰点区布局视角。**完整数学公式见 `MODEL.md`**。

在线示例：`https://<你的用户名>.github.io/<仓库名>/`

## 一、首次部署（一次性，约 3 分钟）

1. **新建仓库**：GitHub → New repository，如 `a-radar`，设为 **Public**，不要勾选 README。
2. **上传全部文件**：`Add file` → `Upload files`，把压缩包解压后的**所有文件与文件夹**（含 `.github`、`scripts`、`scripts/data`）拖入并 Commit。
   - `.github` 隐藏文件夹网页拖拽会被忽略：用 `Create new file` 输入路径 `.github/workflows/refresh-data.yml` 手动粘贴创建（内容见仓库内同名文件，或告诉我向你要）。
3. **启用 Pages**：`Settings` → `Pages` → Source = `Deploy from a branch` → Branch = **`gh-pages`** → Save。
4. 等 Actions 首次跑完（约 3~5 分钟），访问 `https://ducklingli.github.io/a-radar/`。

> 第 3 步若列表里没有 gh-pages 分支，先去 `Actions` 手动 `Run workflow` 一次等它完成。

## 二、之后全自动

- 每交易日 16:30（北京时间）自动扫描并部署；打开页面即最新，顶部显示数据时间戳。
- 手动刷新：`Actions` → `daily-scan` → `Run workflow`（全市场扫描约 3 分钟）。

## 四、方法说明（务必阅读）

**流程**：拉取沪深A股全市场快照（约4600只）→ 剔除 ST/退市/日成交额<3000万/亏损股/上市不足1年 → 按市值取前约420只 → 逐只拉 320 根日K + 所属申万二级板块K线 → 行业中性化估值 → 打分 → 输出 Top50。

**市场温度（连续因子，替代牛熊二分）**：0~100 = 0.45×沪深300一年位置 + 0.30×全A近60日上涨广度 + 0.25×沪深300近60日动量。冷(&lt;34)/温/热(&gt;66) 仅作显示与仓位调制（建议仓位 20%~65% 线性；冷/热区信号档位从严），**不切换打分逻辑**。

**八因子**（候选池内 0-100 分位分，完整公式见 `MODEL.md`）：
- 位置 20%：现价距近一年区间低点的接近度（贴一年高位≈0 分）
- 估值 12%：个股PE 相对所属申万二级行业整体法PE 的对数，行业中性
- 启动 18%：距最近一次**低位金叉**（MA5×MA20 或 MACD，金叉点在一年低位区）天数——≤3日 98 分、4~7日 86 分、8~15日 64 分；无金叉仅企稳基础分；过热/崩跌低分
- 板块 14%·仅冰点区激活：板块60日动量×个股相对板块超额各半；暖/热区权重=0
- 换手 9%：当日换手率分段（0.5%~6% 舒适区高分，过低/过热低分）
- 资金 13%：近5日主力净流入占流通市值比（快照字段 zllr_d5−zllc_d5）
- 波动 8%：20日年化波动率，越低分越高
- 流动性 20%：当日成交额

**操作参考**：温区正常分档（≥75 重点关注/≥60 关注）；冷/热区整体从紧（不出现"重点关注"）。

**重要提示（验证回测 · 近2.5年 · 54个周度截面 · 按市场温度分桶 · 前/后1/3 · 未来20日）**：
- 低位逻辑高分组 vs 低分组：**冷区 +4.5pp（6截面胜率100%）｜温区 −0.7pp｜热区 −2.0pp**。
- 板块因子在冷区正向、暖热区无正增量（行业动量在热区≈追涨，与低位保护冲突）→ v4 起**板块因子仅冰点区激活**。
- 换手/资金因子为 v4 新增（依赖实时快照、无历史存档，采用前瞻积累样本验证方式，尚未能历史回测）。
- 含义：**低位启动逻辑的强区分度集中在市场冰点区**，温度越高越应减少对本榜依赖。顶部温度计给出的建议仓位与提示是第一层过滤器。榜单是量化排序而非预测，不构成投资建议。**完整数学公式见 `MODEL.md`**。
- **启动新鲜度验证（62截面/2.7万样本）**：有低位金叉的股票未来20日平均 +4.2~4.3%（上涨占比58~59%）显著优于无金叉（+2.45%/51.6%）；刚金叉与已启动数日期望收益相当，但首启止损更近、回撤暴露更小——模型偏好早启动属风险结构优化。
- **行业位置共振（v7，54截面/4587低位启动样本）**：行业一年低位 + 个股低位金叉 → 未来20日 **+15.08%/胜率80.6%**；行业高位 → +3.11%/55.2%（差 +11.97pp）→ 打分对低行业位共振 **+5**、高行业位 **−4**，每票输出行业一年位置徽章与本池行业画像（详见 MODEL.md §3g）。

## 五、文件结构

```
index.html                       每日交易闭环页 v7（温度仪表 + 行业联动 + 今日行动 + 逐票执行卡）
live.html                        实时盯盘页（交易时段5s轮询行情 + 状态机阈值触发提醒 + 自选）
MODEL.md                         量化模型数学公式文档（全部因子/权重/行业联动/回测边界）
data.json                        当日扫描结果（scan.py 生成）
fallback-data.js                 兜底数据
scripts/scan.py                  全市场扫描+打分（每日自动运行；v7 输出行业位置/inds 供行业联动）
scripts/backtest_check.py        打分规则滚动回测
scripts/backtest_launch.py       金叉新鲜度验证回测（62截面/2.7万样本）
scripts/backtest_indpos.py       行业位置共振回测（v7 新增）
scripts/build_industry_map.py    重建股票-申万二级行业映射（低频）
scripts/data/sw2_boards.json     124个申万二级板块清单
scripts/data/industry_map.json   约4577只股票->申万二级行业归属
.github/workflows/refresh-data.yml  自动更新+部署（合并站位于仓库根 workflow）
```

> 注：本目录现为合并站 `quant-radar` 的 `radar/` 子目录（仓库根目录 workflow 负责 industry/ 与 radar/ 两个系统的每日自动更新与 gh-pages 发布）。部署整体说明见仓库根 README。
