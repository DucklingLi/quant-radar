# A股多因子雷达 · 量化模型说明（Model Documentation）

> 版本 v4 · 更新于 2026-09-04 · 对应 `scripts/scan.py`
> 本文档用数学语言完整描述当前模型。**本模型仅用于研究参考，不构成投资建议。**

---

## 0. 模型总览

模型由三层构成：

```
市场温度层  heat ∈ [0,100]   —— 连续市场状态，调制信号档位与建议仓位（不切换选股逻辑）
因子打分层  S_i ∈ [0,100]   —— 8 个因子对候选池内每只股票打分
综合分      Score = Σ w_i(heat)·S_i —— 加权合成 → 排序取 Top50
卖出参考层  sell(s) = (估值状态, 卖出区间 zone, 离场线 stop) —— 价值回归 + 短线纪律（见 §5b）
```

---

## 1. 候选池（Universe → Pool）

记全市场 A 股集合为 U（约 4600 只，按流通市值降序拉取快照）。候选池

```
Pool = { s ∈ U : 剔除条件全部通过 }
```

剔除条件（任一命中即剔除）：
1. 名称含 ST / 退（ST、退市整理）
2. 非沪深主板/创业代码（仅 sh6、sz0、sz3 前缀）
3. 最新市盈率 PE_TTM ≤ 0 或缺失（剔除亏损股，规避"低位+绩差=价值陷阱"）
4. 当日成交额 Amount < 3000 万元
5. 上市不足约 1 年（历史日K < 245 根，无 260 日区间可算位置）
6. 近 20 日跌幅 ≤ −18%（下跌趋势未止，不接飞刀）

---

## 2. 市场温度 heat（连续因子）

设 HS300 收盘序列 {P_t}，取 t 为当日：

```
idxpos   = (P_t − min260) / (max260 − min260) × 100          # 一年位置
breadth  = |{ s∈U : 60日涨幅(s) > 0 }| / |U| × 100            # 全A 60日上涨广度
momScore = clamp( HS300近60日涨幅(%) + 25 , 0, 100 ) / 50 × 100  # 指数60日动量(映射0~100)
heat     = 0.45·idxpos + 0.30·breadth + 0.25·momScore
```

- min260 = min{P_{t−259},…,P_t}，max260 同理（约一年窗口）
- clamp(x,0,100) 为截断函数
- **heat 只做两件事**：
  - 建议仓位：`suggestPos = round(20 + 0.45·heat)`（%），即热时最多 65%、冷时 20% 起
  - 信号档位调制（见 §6）；板块因子冷区激活（见 §5）
- 显示标签仅为便于阅读：`cold: heat<34`，`warm: 34≤heat≤66`，`hot: heat>66`。**打分公式本身不含任何 heat 分支（唯一例外：板块因子权重在 cold 区激活），不产生"牛熊切换"式的策略分叉。**

## 3. 八因子定义

每只股票 s ∈ Pool 计算下列因子得分 S_i ∈ [0,100]。**分位分定义**：

对候选池内某原始量集合 X = {x_s}，分位函数

```
q(x_s) = ( # {x∈X : x < x_s} + ½·#{x∈X : x = x_s} ) / |X| × 100
```

### F1 位置因子 S_pos（低位保护，核心）
```
pos_raw(s) = 1 − (P_s − lo260_s) / (hi260_s − lo260_s)
S_pos = q( pos_raw )          # 越高=越接近一年低点；贴一年高位 → pos_raw≈0 → 低分
```
hi260_s / lo260_s 为个股自身 260 日区间高低。此因子从机制上杜绝把"历史高位股"推向前排。

### F2 估值因子 S_val（行业中性）
```
val_raw(s) = ln( PE_s / PE_ind(s) )
S_val = 100 − q( val_raw )   # 取反：相对行业越便宜分越高
```
PE_ind(s) 为个股所属申万二级板块的**整体法 PE(TTM)**（板块全成分加权，由板块行情快照给出）。用对数比使跨行业可比（银行 5 倍 vs 医药 30 倍不被直接比较）。

### F3 启动因子 S_launch（低位刚金叉首启确认；2026-09-04 由"修复因子"升级）

设个股的 MA5、MA20 序列及 MACD(DIF=EMA12−EMA26, DEA=EMA9(DIF))。定义"低位金叉"：

```
金叉日 j ：(MA5_j>MA20_j ∧ MA5_{j−1}≤MA20_{j−1}) 或 (DIF_j>DEA_j ∧ DIF_{j−1}≤DEA_{j−1})
          且 金叉日价格在一年区间内的位置 < 0.70（须发生在低位区，排除高位诱多金叉）
d = 距最近一次低位金叉的天数 = min over {均线金叉, MACD金叉}，120 日内无金叉则 d = ∞
```

启动分（r20=近20日涨幅%）：

```
S_launch(r20,d) =  5    若 r20 > +25 或 r20 < −18     （过热/崩跌未止，一律不碰）
                 98    若 d ≤ 3                        （首启甜点：刚金叉1~3日）
                 86    若 d ≤ 7                        （早启）
                 64    若 d ≤ 15
                 48    若 d ≤ 30
                 42    若无近期金叉但 −5 ≤ r20 ≤ 12     （仅企稳）
                 18    其它
```

**验证（62 截面 · 2.7 万样本 · 未来20日）**：有低位金叉信号的平均 +4.2~4.3%、上涨占比 58~59%，无金叉仅 +2.45%/51.6% —— "启动状态"是分水岭；刚金叉(≤3日)与已启动(8~30日)的期望收益几乎无差异（+4.29% vs +4.30%），但首启止损位更近、回撤暴露更小。**本因子偏好早启动是风险结构优化（入场点质量），不是宣称更高期望收益。**

### F4 板块因子 S_ind（行业轮动 + 行业内选优；**冷区激活**）
```
ind_ret60 = 所属申万二级板块指数近60日涨幅（%）
rel_ret60 = 个股近60日涨幅 − ind_ret60          # 相对板块超额
S_ind = ½·q(ind_ret60) + ½·q(rel_ret60)
```
含义：板块在轮动走强（ind_ret60 高）且个股在板块内也强（rel 高）→ 高分。权重仅在 cold 区非零（见 §5），暖/热区该因子对总分贡献为 0。

### F5 换手因子 S_turn（关注度舒适区）
设 h = 当日换手率（%），分段：
```
S_turn(h) = 10  若 h ≤ 0.2 或 h > 12     （无人问津 / 投机过热）
            40  若 0.2 < h < 0.5
            90  若 0.5 ≤ h ≤ 6           （舒适活跃区）
            55  若 6 < h ≤ 12
```

### F6 资金因子 S_fund（大资金关注度）
```
fund_raw(s) = ( Z5in − Z5out ) / 流通市值 × 100    # 近5日主力净流入占流通市值 %
S_fund = q( fund_raw )
```
Z5in / Z5out 为行情快照的 5 日主力资金累计流入/流出（万元）。

### F7 波动因子 S_vol
```
σ20 = 近20个交易日对数/简单收益的年化波动率（%）
S_vol = 100 − q(σ20)      # 低波动 → 高分
```

### F8 流动性因子 S_liq
```
S_liq = q( 当日成交额 )   # 流动性越好分越高
```

## 4. 综合分

```
Score(s) = w_pos·S_pos + w_val·S_val + w_launch·S_launch + w_ind·S_ind
          + w_turn·S_turn + w_fund·S_fund + w_vol·S_vol + w_liq·S_liq
```

基准权重（w0）：

| w_pos | w_val | w_launch | w_ind | w_turn | w_fund | w_vol | w_liq |
|------|-------|-------|-------|--------|--------|-------|-------|
| 0.20 | 0.12  | 0.18  | 0（待激活） | 0.09 | 0.13 | 0.08 | 0.20 |

**冷区板块激活规则**：

```
若 heat < 34（cold）：
    w_ind = 0.14
    其余 w_i = w0_i × 0.86        （基准权重等比收缩，保持 Σw = 1）
否则：
    w_ind = 0
    其余 w_i = w0_i                （Σw = 1）
```

即在市场冰点期，把 14% 的权重从基础因子让渡给板块动量（行业轮动在冷区经回测验证为正向增益）；市场暖/热期板块因子权重为 0（避免行业动量在热区变相追涨）。

## 5b. 卖出参考（价值回归 + 短线离场纪律）—— v5 新增

对每只上榜股票输出"卖出区间 + 离场止损线"。理论基础与公式：

### 估值状态与价值回归中枢

设 PE_s 为个股 TTM 市盈率，**PE_ind 为"行业内估值中枢"**（候选池内同行业成分股中 **PE∈(0,80]** 集合的下中位数；剔除 PE>80 的微利/困境伪高样本——实测普钢板块内一家 PE≈200 的微利股会把中位数抬高 16 倍；此锚与 F2 估值因子同源）。行业内有效样本 <2 视为无参照（不给出估值回归目标，避免误估）。

```
peR(s) = PE_s / PE_ind          （无参照行业不计算）

状态 est(s) = “极低·周期特征”   若 peR < 0.60   （周期底部/困境股，PE 均值回归不适用）
              “低估修复中”      若 0.60 ≤ peR < 0.85
              “合理”           若 0.85 ≤ peR ≤ 1.15
              “偏高”           若 peR > 1.15
```

**价值回归理论价**（PE 回到行业中位时的理论价）：

```
valC(s) = price(s) / peR(s)        （仅当 0.60 ≤ peR < 0.85 时启用为卖出目标）
```

### 卖出区间（分批兑现带，受技术阻力钳制）

估值目标必须受技术现实约束（一年高点=现实阻力/套牢密集区），且**只在温和低估(0.60~0.85)时启用**估值回归——极低 PE 多为周期底部（航运/钢铁/银行/地产链），对其套用均值回归会得出数倍虚高目标（实测曾把宝钢 5.84 元算出 22 元目标）：

```
修复空间 fix_up = valC − price
若 0.60 ≤ peR < 0.85 且 valC > price×1.15 且 hi260 > price：
    zone = [ price + fix_up × 0.55 ,  min( price + fix_up × 1.05 , hi260 ) ]
    # 兑现带=吃掉约 55%~105% 估值修复空间，上限不得越过一年高点
否则（合理/偏高/极低/无参照）：短线分批止盈带
    zone = [ price × 1.08 ,  min( price × 1.30 , hi260 ) ]
```

hi260 为个股近一年最高收盘价——技术阻力（前期套牢盘）作为卖出区间的自然上限。

### 短线离场线（止损/止盈纪律）

```
launchPx = 最近一次低位金叉当日的收盘价（启动平台 / 成本密集区）
stop(s)  = min( launchPx , MA20(20日均线) ) × 0.97
```

含义：跌破最近金叉启动平台或 20 日均线 3% 视为"启动失败/趋势走坏"，纠错离场。取两者较低者更贴近保护，避免被单日波动震出。

### 卖出纪律与诚实边界

- 卖出区间是**分批落袋纪律**（进入区间即考虑逐步兑现），不是精确价格预测；估值回归中枢依赖行业中位 PE 的稳定性，行业景气变化会整体移动锚。
- 数据仅公开行情，**无盈利预测，故不做 DCF 类"内在价值"宣称**；价值回归以"行业估值中枢"为可验证锚点。
- 每只股票的 buy（启动金叉）与 sell（区间/止损）配对构成完整交易闭环：**F3 解决"何时进"，sell 模块解决"何时出"**。
- 本模块为研究参考，不构成投资建议。

## 6. 信号档位（操作参考）

```
温区（warm）：  Score ≥ 75 → “重点关注”
               Score ≥ 60 → “关注”
               否则        → “观察”
冷/热区：       Score ≥ 78 → “关注”
               否则        → “观察”      （冷热两区不出现“重点关注”，从严）
```

“重点关注/关注/观察”是**分档标签**，表达信号强弱排序，不是买入指令。

## 7. 验证回测（诚实边界）

方法：近 2.5 年 · 54 个周度滚动截面 · 每组取前/后 1/3 · 未来 20 日平均收益差（pp=百分点）。

| 市场温度 | 高分组 − 低分组 | 截面胜率 |
|---------|----------------|---------|
| 冷区 heat<34 | **+4.5pp** | 100%（6截面） |
| 温区 | −0.7pp | 28% |
| 热区 heat>66 | −2.0pp | 39% |

**已明确验证**：
- 位置/启动/低波 为主的低位逻辑，其正向区分度集中在**市场冰点区**；越热越不应依赖本榜。
- 板块因子：冷区正向增益；暖/热区无增量（行业动量≈追涨，与低位保护冲突）→ 因此设计为**仅冷区激活**。
- 早期"趋势/动量追涨"版已被弃用：牛市 +4.4pp 但高分组 42% 是贴一年高位股，熊市 −2.8pp 反向。

**尚未能历史验证（需前瞻积累）**：换手因子、资金因子依赖盘中快照字段，历史无存档，无法在旧截面上回测——它们通过每日运行积累样本后另行验证。模型会每日自动运行，样本累积后可持续检验。

**方法局限**：候选池按今日市值选取（存在幸存者偏差）；截面回测未含交易成本；分桶样本数有限。

## 8. 一句话总结

> Score = 位置·0.20 + 估值·0.12 + **启动·0.18** + 板块·0.14·𝕀(冰点) + 换手·0.09 + 资金·0.13 + 波动·0.08 + 流动·0.20
> （非冰点期板块项归 0，其余权重恢复基准）
> 且整套打分只应在 **heat 足够低** 时被认真对待 —— 温度越高，参考价值越低。
