A股多因子雷达 · 量化模型数学说明

三层结构：市场温度 heat 连续调制 → 八因子 + 行业共振打分 → 卖出参考（价值回归 + 离场纪律）。对应 scan.py，完整代码即文档。

⚠
诚实声明：本文档是当前模型的完整数学语言描述。模型仅用于研究参考，不构成投资建议；回测边界见 §7——本模型的强区分度集中在市场冰点区，温度越高参考价值越低。

模型总览

三层 · 连续调制 · 无策略分叉
市场温度层 heat ∈ [0,100] —— 连续市场状态，调制信号档位与建议仓位（不切换选股逻辑） 因子打分层 S_i ∈ [0,100] —— 8 个因子对候选池内每只股票打分 综合分 Score = Σ w_i(heat)·S_i —— 加权合成 → 排序取 Top50 卖出参考层 sell(s) = (估值状态, 卖出区间 zone, 离场线 stop) —— 价值回归 + 短线纪律（§5b）
1

候选池 Universe → Pool

全 A ≈4600 只 → 市值取前约 450 只入池打分

记全市场 A 股集合为 U（约 4600 只，按流通市值降序拉取快照）。候选池 Pool = { s ∈ U : 剔除条件全部通过 }，任一命中即剔除：

剔除条件说明
名称含 ST / 退ST、退市整理
代码前缀仅 sh6 / sz0 / sz3（沪深主板·创业板）
PE_TTM ≤ 0 或缺失剔除亏损股 规避"低位+绩差=价值陷阱"
当日成交额 < 3000 万流动性下限
上市不足约 1 年历史日K < 245 根，无 260 日区间可算位置
近 20 日跌幅 ≤ −18%下跌趋势未止，不接飞刀
2

市场温度 heat

连续因子 · 只调仓位与档位

设 HS300 收盘序列 {P_t}，t 为当日：

idxpos = (P_t − min260) / (max260 − min260) × 100 # 一年位置 breadth = |{ s∈U : 60日涨幅(s) > 0 }| / |U| × 100 # 全A 60日上涨广度 momScore = clamp( HS300近60日涨幅(%) + 25 , 0, 100 ) / 50 × 100 # 指数60日动量 → 0~100 heat = 0.45·idxpos + 0.30·breadth + 0.25·momScore

min260 / max260 为近 260 交易日窗口极值；clamp 为截断函数。heat 只做两件事：

用途公式 / 规则
建议仓位suggestPos = round( 20 + 0.45·heat ) % → 冷 20% 起 · 热 ≤ 65%
信号档位温区正常分档；冷/热区从紧且无"重点关注"（§6）
板块因子仅 heat < 34（cold）时激活（§4）

显示标签便于阅读：cold <34 warm 34~66 hot >66——打分公式本身不含任何 heat 分支（唯一例外：板块因子冷区激活），不产生"牛熊切换"式策略分叉。

3

八因子定义

S_i ∈ [0,100] · 分位法 + 分段函数

每只股票 s ∈ Pool 计算各因子得分。候选池内某原始量集合 X = {x_s} 的分位函数：

q(x_s) = ( #{ x∈X : x < x_s } + ½·#{ x∈X : x = x_s } ) / |X| × 100
F1 · 位置因子 S_pos 低位保护（核心）
pos_raw(s) = 1 − (P_s − lo260_s) / (hi260_s − lo260_s) S_pos = q( pos_raw ) # 越高=越接近一年低点；贴一年高位 → pos_raw≈0 → 低分

hi260 / lo260 为个股自身 260 日区间高低。此因子从机制上杜绝把"历史高位股"推向前排。

F2 · 估值因子 S_val 行业中性
val_raw(s) = ln( PE_s / PE_ind(s) ) S_val = 100 − q( val_raw ) # 取反：相对行业越便宜分越高

PE_ind 为所属申万二级板块整体法 PE。对数比使跨行业可比（银行 5 倍 vs 医药 30 倍不被直接比较）。

F3 · 启动因子 S_launch 低位刚金叉首启确认 · 2026-09-04 由"修复因子"升级

设 MA5、MA20 序列与 MACD（DIF=EMA12−EMA26，DEA=EMA9(DIF)），定义低位金叉：

金叉日 j：(MA5_j>MA20_j ∧ MA5_{j−1}≤MA20_{j−1}) 或 (DIF_j>DEA_j ∧ DIF_{j−1}≤DEA_{j−1}) 且 金叉日价格在一年区间内的位置 < 0.70（排除高位诱多金叉） d = 距最近一次低位金叉的天数 = min{均线金叉, MACD金叉}；120 日内无金叉则 d = ∞

启动分（r20 = 近 20 日涨幅 %）：

S_launch(r20,d) = 5 若 r20 > +25 或 r20 < −18 # 过热/崩跌未止，一律不碰 98 若 d ≤ 3 # 首启甜点：刚金叉 1~3 日 86 若 d ≤ 7 # 早启 64 若 d ≤ 15 48 若 d ≤ 30 42 若无近期金叉但 −5 ≤ r20 ≤ 12 # 仅企稳 18 其它
验证（62 截面 · 2.7 万样本 · 未来20日）：有低位金叉平均 +4.2~4.3%（上涨占比 58~59%），无金叉仅 +2.45% / 51.6% —— "启动状态"是分水岭；刚金叉(≤3日)与已启动(8~30日)期望收益几乎无差（+4.29% vs +4.30%），但首启止损更近、回撤暴露更小。本因子偏好早启动是风险结构优化（入场点质量），不是宣称更高期望收益。
F4 · 板块因子 S_ind 行业轮动 + 行业内选优 · 仅冷区激活
ind_ret60 = 所属申万二级板块指数近60日涨幅（%） rel_ret60 = 个股近60日涨幅 − ind_ret60 # 相对板块超额 S_ind = ½·q(ind_ret60) + ½·q(rel_ret60)

权重仅在 cold 区非零（§4）；暖/热区该因子对总分贡献为 0（避免热区变相追涨行业）。

F5 · 换手因子 S_turn 关注度舒适区
S_turn(h) = 10 若 h ≤ 0.2 或 h > 12 # 无人问津 / 投机过热 40 若 0.2 < h < 0.5 90 若 0.5 ≤ h ≤ 6 # 舒适活跃区 55 若 6 < h ≤ 12
F6 · 资金因子 S_fund 大资金关注度
fund_raw(s) = ( Z5in − Z5out ) / 流通市值 × 100 # 近5日主力净流入占流通市值 % S_fund = q( fund_raw )
F7 · 波动因子 S_vol 低波优先
σ20 = 近20个交易日收益的年化波动率（%） S_vol = 100 − q(σ20) # 低波动 → 高分
F8 · 流动性因子 S_liq
S_liq = q( 当日成交额 ) # 流动性越好分越高
3g

行业联动层

v7 · 选股参考行业位置 · 共振修正经回测校准
posInd(s) = 所属申万二级行业指数近一年区间位置 (0~1) （板块 330 根日K，取近 260 交易日高低点；0=行业近一年低点 · 1=高点） Adj_ind(s) = +5 若 posInd ≤ 0.35 且 个股距最近低位金叉 ≤ 7 日 # 行业底部共振 −4 若 posInd ≥ 0.65 # 高位行业风险折价 0 其他

校准依据（backtest_indpos.py · 54 周度截面 · 约 4587 个"低位启动"样本 · 未来 20 日）：

截面时行业一年位置样本平均收益上涨占比
行业低位 (<0.33)723+15.08%80.6%
行业中位2062+4.37%62.1%
行业高位 (>0.67)1802+3.11%55.2%
低行业位 vs 高行业位 = +11.97pp。"行业趴在一年低位、个股率先低位金叉启动"（左侧行业里的右侧个股）是最优共振形态；行业已处高位后的低位启动（分化/补涨）期望显著偏低——因此本层奖励前者、折价后者。修正幅度取差分的一小部分（+5/−4），避免过度拟合。

口径边界：行业位置 ≠ 行业动量；低位行业也可能持续阴跌，因此共振修正只作用于已有"个股低位金叉"确认的标的，不单独催票。

3h

质量层（ROE/营收增速）

v9 · 正交于位置/动量的独立增量 · 回测单调验证
qAdj(s) = +3 若 ROE > 15 或 (ROE > 10 且 营收增速 ≥ 0) # 优质公司低位启动 −2 若 0 < ROE < 5 或 营收增速 < −10% # 微利/营收萎缩：弱质折价 0 其余 / 无财务覆盖（不惩罚） Score(s) = 八因子加权 + Adj_ind(s) + qAdj(s)

校准依据（backtest_quality.py · 2025-09~2026-08 全市场 14844 个低位金叉启动事件 · 未来 20 日 · 财务取 2026-06-30 中报）：

按加权 ROE 分桶样本平均收益上涨占比
亏损4893+0.48%48.3%
0~5%7289+0.95%50.6%
5~10%1913+1.51%52.5%
10~15%287+2.28%51.6%

ROE 分层完全单调；深低位（位置≤0.33）样本内 优质(ROE>10 且营收不降) +6.61%/胜率62.8% vs 弱质 +1.25%/53.8% —— 质量在"低位启动"里是独立增量，与"追好消息被证伪"相反，因此入打分。营收增速同向单调（<−10%: +0.14% → >20%: +2.28%）。修正取差分小部分（+3/−2）防过拟合。

口径边界：财务按报告期披露（4/30 后一季报、8/31 后中报、10/31 后三季报自动切换）；周期股景气底部 ROE 低属正常，折价只作用于"低位启动但质地弱"的标的；东财取数失败时全部 qAdj=0，退化为 v7 口径。页面：行内绿点=背书 / 琥珀点=折价，悬浮框显示 ROE/营收明细。

# 冷区板块激活规则（唯一的 heat 分支） 若 heat < 34（cold）: w_ind = 0.14 ；其余 w_i = w0_i × 0.86 # 等比收缩，保持 Σw = 1 否则: w_ind = 0 ；其余 w_i = w0_i # Σw = 1

冰点期把 14% 权重从基础因子让渡给板块动量（行业轮动冷区回测为正向增益）；暖/热期板块因子权重 0（避免行业动量在热区变相追涨）。

5b

卖出参考

v5 · 价值回归 + 短线离场纪律
估值状态与价值回归中枢

PE_ind 为行业内估值中枢：候选池内同行业成分 PE∈(0,80] 集合的下中位数（剔除 PE>80 微利/困境伪高样本——实测普钢板块内一家 PE≈200 的微利股会把中位数抬高 16 倍）；行业内有效样本 <2 视为无参照，不给出回归目标。

peR(s) = PE_s / PE_ind # 无参照行业不计算 状态 est(s) = “极低·周期特征” 若 peR < 0.60 # 周期底部/困境股，PE 均值回归不适用 “低估修复中” 若 0.60 ≤ peR < 0.85 “合理” 若 0.85 ≤ peR ≤ 1.15 “偏高” 若 peR > 1.15 valC(s) = price(s) / peR(s) # 回归理论价（仅 0.60~0.85 时启用为目标）
卖出区间（分批兑现带 · 受技术阻力钳制）
修复空间 fix_up = valC − price 若 0.60 ≤ peR < 0.85 且 valC > price×1.15 且 hi260 > price： zone = [ price + fix_up×0.55 , min( price + fix_up×1.05 , hi260 ) ] # 兑现带=吃掉约 55%~105% 估值修复空间，上限不越过一年高点 否则（合理/偏高/极低/无参照）：短线分批止盈带 zone = [ price × 1.08 , min( price × 1.30 , hi260 ) ]

hi260 = 个股近一年最高收盘价（前期套牢盘 = 技术阻力上限）。估值目标永远受此钳制——修复空间再大也不越过前高（避免"纸上目标"；曾把宝钢 5.84 元误算 22 元目标，已修正）。

短线离场线（止损/止盈纪律）
launchPx = 最近一次低位金叉当日的收盘价（启动平台 / 成本密集区） stop(s) = min( launchPx , MA20 ) × 0.97

跌破金叉启动平台或 20 日均线 3% 视为"启动失败/趋势走坏"，纠错离场。取两者较低者更贴近保护，避免被单日波动震出。

诚实边界：卖出区间是分批落袋纪律（进入区间即考虑逐步兑现），不是精确价格预测；估值中枢依赖行业中位 PE 的稳定性，行业景气变化会整体移动锚。数据仅公开行情，无盈利预测，故不做 DCF 类"内在价值"宣称。F3 解决"何时进"，本模块解决"何时出"——两者配对构成完整交易闭环。

信号档位（操作参考）

分档标签 ≠ 买入指令
温区（warm）： Score ≥ 75 → “重点关注” Score ≥ 60 → “关注” 否则 → “观察” 冷/热区： Score ≥ 78 → “关注” 否则 → “观察” # 冷/热两区不出现“重点关注”，整体从严

"重点关注 / 关注 / 观察"表达信号强弱排序，不是买入指令。

验证回测（诚实边界）

近2.5年 · 54 周度截面 · 前/后 1/3 · 未来 20 日
市场温度高分组 − 低分组截面胜率
冷区 heat<34+4.5pp100%（6 截面）
温区−0.7pp28%
热区 heat>66−2.0pp39%

已明确验证：

  • · 位置/启动/低波为主的低位逻辑，正向区分度集中在市场冰点区；越热越不应依赖本榜。
  • · 板块因子冷区正向增益；暖/热区无增量（行业动量≈追涨，与低位保护冲突）→ 设计为仅冷区激活。
  • · 行业位置共振（v7）：低行业位+低位启动 +15.08% / 80.6% vs 高行业位 +3.11% / 55.2%（差 +11.97pp）→ 加 +5 / 折价 −4（§3g）。
  • · 早期"趋势/动量追涨"版已弃：牛市 +4.4pp 但高分组 42% 贴一年高位股，熊市 −2.8pp 反向。
尚未能历史验证（需前瞻积累）：换手、资金因子依赖盘中快照字段（历史无存档），无法在旧截面回测——模型每日自动运行，样本累积后另行验证。
方法局限：候选池按今日市值选取（幸存者偏差）；截面回测未含交易成本；分桶样本数有限。以上数字均为信号层方向概率，不是可交易净值。
8

一句话总结

Score = 位置·0.20 + 估值·0.12 + 启动·0.18 + 板块·0.14·𝕀(冰点) + 换手·0.09 + 资金·0.13 + 波动·0.08 + 流动·0.20 [+ 行业共振 Adj_ind] [+ 质量修正 qAdj] （非冰点期板块项归 0，其余权重恢复基准） 且整套打分只应在 heat 足够低时被认真对待 —— 温度越高，参考价值越低。
